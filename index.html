Java in English · for a complete beginner英文 Java · 写给完全零基础

One small page. One idea.一次只读一页，一次只学一个概念。

I know nothing about Java. I want to learn it in English, not in Chinese. So every page gives one idea, five new words, and three questions I answer out loud.我不懂 Java，而且我想用英文学，不是用中文背。所以每一页只讲一个概念、给五个新词、三道要出声回答的题。

Short answer先给答案This site teaches Java in English, one question per page. Pick a question; when a word or an idea is missing, the page says which lesson to read first.这个站用英文教 Java，一页一个问题。先挑一道题读；卡在哪个词、哪个概念，页面会告诉你先补哪一节课。

01Three interview questions三道面试题

Three for now, all taken from my own résumé. Each one is a page: a 60-second answer, the mechanism behind it, and the new questions it opens.现在三道，全部从我的简历里挖出来的。一道一页：60 秒答案、背后的机制、以及它又长出了哪些新问题。

01 说说 Java 中 HashMap 的原理？桶数组、链表与红黑树、扩容、线程安全——开场最常问的那道。 60 秒
02 微信回调同时来三条：只发一次货、库存只扣一次。幂等表、状态 CAS、分布式锁——支付链路上那道。 60 秒
03 前面加一层 Redis，P95 从 800 毫秒降到 240 毫秒——缓存怎么用？命中率、穿透/击穿/雪崩、Cache Aside——缓存那道。 60 秒

A fourth one gets added when the third one is solid.第三道读透了再加第四道。

03How to read a page怎么读一页

  1. Press 🔊 at the top. Follow the words with your eyes. Twice is enough.点页面顶部的 🔊，眼睛跟着字走。两遍就够。
  2. Switch to 中英 if a sentence is too hard. Read the English first, then the Chinese.句子太难就切到 中英：先读英文，再看中文。
  3. Read the 60-second answer, then the mechanism. The new questions are at the bottom of the page.先读 60 秒答案，再读机制。新问题在同一页的底部。
  4. Answer the three questions at the end out loud, not in your head.最后三道自测要出声回答，不要只在心里想。

Twenty minutes a page. One page a day is enough.一页二十分钟。一天一页就够。

04Why English, and why so slow为什么要英文、为什么这么慢

In an interview the words are English: bucket, collision, resize. If I only know the Chinese word, I hear a sound I cannot follow.面试里蹦出来的是英文词：bucket、collision、resize。如果我只知道中文说法，听到的就是一串抓不住的声音。

So this site is slow on purpose. One question per page, five words, one picture.所以这个网站是故意慢的：一页一道题、五个词、一张图。
