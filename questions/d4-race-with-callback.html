Follow-up 03追问 03

Two writers, one row, one winner.两个写者、一行数据、一个赢家。

Both the close job and the payment callback try to move the same order. Whoever's CAS returns 1 wins; the other sees the new status and takes the other branch.关单任务和支付回调都在改同一个订单。谁的条件更新先成功谁赢；另一个读到新状态，走另一条分支。

Short answer先给答案Close first: status becomes CLOSED, then the callback's CAS gets 0 rows and it refunds. Callback first: status becomes PAID, then the close job's CAS gets 0 rows and it does nothing.关单先成功：状态是 CLOSED，回调的 CAS 影响 0 行，走退款。回调先成功：状态是 PAID，关单任务的 CAS 影响 0 行，什么都不做。

01The two orders两种顺序

Order of events先后Result结果
close wins关单先CLOSED → callback sees 0 rows → refundCLOSED → 回调 0 行 → 退款
callback wins回调先PAID → close sees 0 rows → nothingPAID → 关单 0 行 → 什么都不做

Note the asymmetry: one branch must refund, the other must do nothing. Both are “safe”, but only one is correct behaviour.注意两边不对称：一边必须退款，一边必须什么都不做。都“安全”，但只有一个是对的。
