Follow-up 02追问 02

One is missing data; the other is a hot key expiring.一个是数据不存在，一个是热 key 过期。

These two get mixed up in interviews more than any other pair.这两个在面试里被混得最多。

Short answer先给答案Penetration: the key does not exist anywhere, so every request falls through to the DB — the cache cannot help by definition. Breakdown: the key exists and is hot, but it expires and thousands of threads rebuild it at once.穿透：这个 key 哪儿都不存在，缓存天然帮不上，每个请求都打到库。击穿：key 存在且很热，但恰好过期，上千线程同时重建。

must know必背3 min3 分钟

01Same symptom, different fix症状像，治法完全不同

key exists?key 存在吗no, never不存在，从来没有yes, and it is hot存在，而且很热
cache role缓存作用no hit possible永远不命中hit until it expires命中到过期那一刻
fix治法bloom filter / null cache布隆 / 空值缓存rebuild lock / logical expire重建加锁 / 逻辑过期

A Bloom filter can say “definitely absent” with a few MB. That is why it fits penetration and nothing else.布隆过滤器能用几 MB 断言“一定不存在”，所以它只对穿透有效。
