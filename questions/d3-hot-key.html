One key, one shard, one core.一个 key，一个分片，一个核。

Sharding by key does not help when a single key carries most of the traffic.按 key 分片对“单 key 扛住大部分流量”完全无效。

Short answer先给答案Two moves: local cache on each application node (reads never leave the box), and split the key itself (key:1 … key:16) with a random suffix on write and a merge on read. Do not try to fix it with more shards.两招：每个应用节点加本地缓存（读不出机器），以及把 key 本身拆开（key:1…key:16），写时随机后缀、读时聚合。靠加更多分片解决不了单 key 热点。
