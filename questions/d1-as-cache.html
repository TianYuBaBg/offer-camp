Fine as a scratch map. Wrong as a cache.当临时表可以，当缓存不对。

A cache needs eviction, expiry and a memory bound. HashMap has none of the three.缓存需要淘汰、过期、内存上限——HashMap 三样都没有。

Short answer先给答案HashMap grows without limit and never expires anything, so a long-running process fills the heap and dies. If you want a local cache, use Caffeine (bounded, TTL, LRU/LFU); if you need it shared, use Redis.HashMap 无上限、不过期，长时间运行会把堆撑爆。要本机缓存就用 Caffeine（有上限、TTL、淘汰策略）；要共享就用 Redis。
