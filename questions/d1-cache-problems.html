Three names, three different root causes.三个名字，三种不同的根因。

Penetration is missing data, breakdown is one hot key expiring, avalanche is many keys at once.穿透是数据不存在，击穿是一个热 key 过期，雪崩是一大批 key 同时失效。

Short answer先给答案Penetration: query something that does not exist, so every request hits the DB — fix with a null cache or a Bloom filter. Breakdown: one hot key expires and thousands of threads rebuild it — fix with a lock or logical expiry. Avalanche: many keys expire together or Redis dies — fix with jittered TTL, local cache and a rate limiter.穿透：查根本不存在的数据，每次都打到库——用空值缓存或布隆过滤器。击穿：一个热 key 过期，上千线程同时重建——用锁或逻辑过期。雪崩：大批 key 同时过期或 Redis 挂了——用随机 TTL、本地缓存、限流。
