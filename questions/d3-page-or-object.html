Follow-up 06追问 06

Objects. Page-level caching invalidates too easily.缓存对象。整页缓存的失效太容易。

One comment on the page and a whole page cache is useless.页面里多一条评论，整页缓存就白做了。

Short answer先给答案Cache the object (product detail, category list) with a TTL, and compose the page. Page-level caching only works for truly static fragments — and then it is a CDN's job.按对象缓存（商品详情、分类列表）加 TTL，页面在应用层拼装。整页缓存只适合真正静态的片段，而那本来就该交给 CDN。
