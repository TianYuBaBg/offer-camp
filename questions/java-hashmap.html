Question 1 · HashMap第 1 题 · HashMap

How does HashMap work?HashMap 是怎么工作的？

A box of small boxes. Give it a key, get back a value, very fast.一个装着小盒子的盒子：给它 key，它很快还你 value。

Must know必背HashMapHashMapspeak 60s60 秒口播7 lessons关联 7 课

01One sentence一句话

Say this first先说这句

A HashMap is a box of small boxes. You give it a key, and it gives you back a value very fast. Inside, it uses an array. Each box in the array is called a bucket. When two keys fall into the same bucket, they stand in a line.HashMap 是一个装着小盒子的盒子：给它 key，它很快还你 value。底层是一个数组，数组里每一格叫一个桶。两个 key 落进同一个桶时，就排成一队（链表）。

03How put worksput 的六步

  1. Make the table — the first put creates the array with 16 buckets.建表——第一次 put 才创建 16 格数组。
  2. Compute the hash — (h = key.hashCode()) ^ (h >>> 16), mixing high bits into low bits.算 hash——(h = key.hashCode()) ^ (h >>> 16)，把高位混进低位。
  3. Find the bucket — index = (n - 1) & hash; because n is a power of two this equals hash % n, but faster.定位桶——index = (n - 1) & hash；因为 n 是 2 的幂，这等价于 hash % n，但更快。
  4. Empty bucket? — put a new node there. Done.桶是空的？——放一个新节点，结束。
  5. Not empty? — same key → replace the value; different key → go to the end of the line; at 8 items the bucket may become a tree.不空？——key 相同就覆盖 value；不同就挂到链尾；到 8 个可能树化。
  6. Too full? — if size > capacity × 0.75, double the array.太满了？——超过 容量 × 0.75 就扩容一倍。
if ((tab = table) == null || (n = tab.length) == 0)
    n = (tab = resize()).length;                  // 1. create the array
if ((p = tab[i = (n - 1) & hash]) == null)
    tab[i] = newNode(hash, key, value, null);     // 2. empty bucket
else {
    if (p.hash == hash && (p.key == key || key.equals(p.key)))
        e = p;                                    // 3. same key: replace
    else if (p instanceof TreeNode)
        e = ((TreeNode) p).putTreeVal(...);   // 4. bucket is a tree
    else {
        for (int binCount = 0; ; ++binCount) {
            if ((e = p.next) == null) {
                p.next = newNode(hash, key, value, null);  // 5. add at the end
                if (binCount >= TREEIFY_THRESHOLD - 1)
                    treeifyBin(tab, hash);                 //    line too long: tree
                break;
            }
            if (e.hash == hash && (e.key == key || key.equals(e.key))) break;
            p = e;
        }
    }
    if (e != null) { V old = e.value; e.value = value; return old; }
}
++modCount;
if (++size > threshold) resize();                 // 6. too full: grow
return null;

04Why resize is cheap为什么扩容不贵

From 16 to 32, an item has only two possible places: where it is, or where it is + 16. One bit decides:从 16 扩到 32，每个元素只有两种去处：原位，或者原位 + 16。看一位就够：

if ((e.hash & oldCap) == 0)  keep the item at index i
else                          move it to index i + oldCap

So HashMap does not recompute every hash. It splits each bucket into two short lines.所以不用重算每个 hash，只是把每个桶拆成两条短链。

06Why it is not thread-safe为什么线程不安全

Two threads call put at the same time: both read size, both write it back — one update is lost. In JDK 7, two resizes at once could bend a list into a circle and get would spin forever.两个线程同时 put：都读到 size、都写回——丢掉一次更新。JDK 7 里两个线程同时扩容，甚至能把链拧成环，get 就永远转不出来。

So in a web application I use ConcurrentHashMap: it locks only the bucket being changed.所以 Web 应用里我用 ConcurrentHashMap：它只锁正在改的那个桶。

07Say it in 60 seconds60 秒照念稿

Read out loud, then say it your own way先照着念，再换成自己的话

A HashMap is an array of buckets. You give it a key, it computes a hash, and the hash tells it which bucket to use.HashMap 是一个桶数组。给它 key，它算出一个 hash，hash 决定用哪个桶。

If the bucket is empty, the value goes in. If it already has items with different keys, they stand in a line. When a line reaches 8 items and the array has at least 64 buckets, it becomes a red-black tree, so the worst case is O(log n) instead of O(n).桶是空的就直接放。桶里已经有别的 key，就排成一条链。链到 8 个、且数组至少 64 格，就变成红黑树，最坏情况从 O(n) 降到 O(log n)。

When the map is 75 percent full, the array doubles. Because the size is a power of two, each item either stays or moves to bucket + old size, so no hash is recomputed.装到 75% 就扩容一倍。因为容量是 2 的幂，每个元素要么原位、要么挪到原位 + 旧容量，不用重算 hash。

HashMap is fast but not thread-safe, so in a web application I use ConcurrentHashMap.HashMap 快，但线程不安全，所以 Web 应用里我用 ConcurrentHashMap。
