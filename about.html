Learn Java, in English.用英文学 Java。

Short sentences, real pronunciation, and a Chinese line whenever you need it.短句子、真人发音，需要的时候还有一行中文。

Short answer先给答案A plain HTML site with a language switch: seven short lessons, one interview question and a word list. English first; Chinese when a sentence is too hard.一个纯 HTML 小站，带语言切换：七节短课、一道面试题、一份词表。英文优先，句子太难时看中文。

English first英文优先no tracking无追踪

01Why this site exists为什么做这个站

I am learning Java and English at the same time. If I read Java in Chinese, I learn the idea only. If I read it in English, I learn the idea and the words I will hear in an interview.我在同时学 Java 和英语。用中文读 Java，只学到概念；用英文读，概念和面试里会听到的词一起学到。

02Three buttons三个按钮

  • 中文 — read only Chinese.中文——只看中文。
  • 中英 — English first, Chinese under it. Good for the hard pages.中英——先英文，下面跟一行中文。难页用这个。
  • English — the real test.English——真正的考试模式。

03How to use it怎么用

  1. Press 🔊 and follow with your eyes.点 🔊，眼睛跟着字走。
  2. Say five new words out loud, after YouGlish.跟着 YouGlish 把五个新词读出声。
  3. Answer the checks out loud, then read the page again if you could not.自测题出声回答，答不出来就回去再读。
