contiguous /kənˈtɪɡjuəs/ Touching, with no gaps. ▶ hear it
linked list /lɪŋkt lɪst/ Boxes joined by arrows, one after another. ▶ hear it

pointer /ˈpɔɪntər/ A value that says where the next box is. ▶ hear it

traverse /trəˈvɜːrs/ Walk through items one by one. ▶ hear it
tree /triː/ Nodes with children below them. ▶ hear it

•HashMap

HashMap /hæʃ mæp/ A map that finds values by key, using an array of buckets. ▶ hear it
key /kiː/ The name you look things up by. ▶ hear it
value /ˈvæljuː/ The thing stored under a key. ▶ hear it
entry /ˈentri/ One key-value pair. ▶ hear it
hash /hæʃ/ A number computed from a key. ▶ hear it
hash function /hæʃ ˈfʌŋkʃn/ The machine that turns a key into a number. ▶ hear it
hashCode /hæʃ koʊd/ Java method that gives an int for an object. ▶ hear it
bucket /ˈbʌkɪt/ One box of the array. ▶ hear it
collision /kəˈlɪʒn/ Two keys with the same bucket. ▶ hear it
capacity /kəˈpæsəti/ How many buckets the array has now. ▶ hear it
load factor /loʊd ˈfæktər/ How full before it grows. Default 0.75. ▶ hear it
threshold /ˈθreʃhoʊld/ capacity × load factor. Crossing it triggers resize. ▶ hear it
resize /ˌriːˈsaɪz/ Double the array and move the items. ▶ hear it
treeify /ˈtriːɪfaɪ/ Turn a long bucket line into a tree. ▶ hear it
equals /ˈiːkwəlz/ Java method that says whether two keys are the same. ▶ hear it

•Complexity

time complexity /taɪm kəmˈpleksəti/ How run time grows with data size. ▶ hear it
Big O /bɪɡ oʊ/ The notation for that growth. ▶ hear it
constant /ˈkɑːnstənt/ Does not grow: O(1). ▶ hear it
linear /ˈlɪniər/ Grows in a line: O(n). ▶ hear it
logarithmic /ˌlɔːɡəˈrɪðmɪk/ Grows very slowly: O(log n). ▶ hear it
quadratic /kwɑːˈdrætɪk/ Grows like n × n: O(n²). ▶ hear it
amortized /əˈmɔːrtaɪzd/ Average cost over many operations. ▶ hear it

•Concurrency

concurrent /kənˈkɜːrənt/ Happening at the same time. ▶ hear it

lock /lɑːk/ Lets only one worker touch something. ▶ hear it
synchronized /ˈsɪŋkrənaɪzd/ Java keyword: one thread at a time here. ▶ hear it
volatile /ˈvɑːlətl/ Java keyword: always read the latest value. ▶ hear it
