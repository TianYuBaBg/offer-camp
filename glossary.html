contiguous /kənˈtɪɡjuəs/ Touching, with no gaps.连续的：紧挨着没空隙 ▶ hear it
linked list /lɪŋkt lɪst/ Boxes joined by pointers.链表：用指针串起来 ▶ hear it
node /noʊd/ A value plus a pointer.节点：值 + 指针 ▶ hear it
pointer /ˈpɔɪntər/ Where the next box is.指针：下一个在哪 ▶ hear it
head /hed/ The first node.头节点：第一个 ▶ hear it
null /nʌl/ Nothing.null：空 ▶ hear it
traverse /trəˈvɜːrs/ Walk through one by one.遍历：一个个走 ▶ hear it
tree /triː/ Nodes with children.树：带孩子的节点 ▶ hear it
root /ruːt/ The top node.根：最上面 ▶ hear it
leaf /liːf/ A node with no children.叶子：没有孩子 ▶ hear it
height /haɪt/ How many levels.高度：有几层 ▶ hear it
balanced /ˈbælənst/ Left and right are similar.平衡：左右差不多 ▶ hear it

key /kiː/ The name you look things up by.key：用来查的名字 ▶ hear it
value /ˈvæljuː/ The thing stored under a key.value：存在 key 下的东西 ▶ hear it
entry /ˈentri/ One key-value pair.entry：一个键值对 ▶ hear it
hash /hæʃ/ A number computed from a key.hash：由 key 算出的编号 ▶ hear it

bucket /ˈbʌkɪt/ One box of the array.桶：数组的一格 ▶ hear it
collision /kəˈlɪʒn/ Two keys in one bucket.冲突：两个 key 一个桶 ▶ hear it
capacity /kəˈpæsəti/ How many buckets now.容量：现在有多少格 ▶ hear it

threshold /ˈθreʃhoʊld/ capacity × load factor.阈值：容量 × 负载因子 ▶ hear it

treeify /ˈtriːɪfaɪ/ Turn a long line into a tree.树化：长链变树 ▶ hear it
equals /ˈiːkwəlz/ Says two keys are the same.equals：判断 key 相同 ▶ hear it
cache /kæʃ/ A fast copy of slow data.缓存：慢数据的快副本 ▶ hear it
