Lesson 5 · Complexity第 5 课 · 复杂度

What is O(1), O(n), O(log n)?什么是 O(1)、O(n)、O(log n)？

Big O is not about seconds. It is about how the cost grows when the data grows.大 O 说的不是几秒，而是“数据变多时，代价怎么变”。

Short answer先给答案Big O is not seconds; it is how the number of steps grows when the data grows. O(1) one step · O(log n) halve each time · O(n) one by one · O(n²) every pair.大 O 说的不是几秒，而是“数据变多时步数怎么长”：O(1) 一步；O(log n) 每次砍一半；O(n) 一个一个来；O(n²) 两两配对。

Basics基础complexity复杂度must know必背

01The idea先有一个画面

Think of it like this先这样想Finding a shoe. (1) You know the box number — open one box. (2) The boxes have no order — open one by one. (3) The boxes are sorted by size — cut the range in half each time.找鞋：(1) 你知道在哪一格——开一格； (2) 全乱堆着——一格一格开； (3) 按大小排好了——每次砍一半。

That is O(1), O(n), O(log n). The letter is the data size; the function is how many steps you need.这就是 O(1)、O(n)、O(log n)。字母是数据量，函数是需要的步数。

02How to read it怎么读出来

“O” is said “big O”. “O(1)” is “big O of one, constant time”. “O(log n)” is “big O of log n”.“O”读作 big O；“O(1)”读 big O of one，也叫常数时间；“O(log n)”读 big O of log n。

We drop the small parts. O(2n + 5) is O(n); O(n² + n) is O(n²). Big O cares about the shape of the curve, not the exact number.小项会被丢掉：O(2n + 5) 就是 O(n)，O(n² + n) 就是 O(n²)。大 O 只看曲线的形状，不看具体数字。

03Where you meet it你会在哪里遇到它

  • HashMap get: O(1) on average, O(log n) in a bad bucket, O(n) in the worst case.HashMap 的 get：平均 O(1)，桶里成了树是 O(log n)，最坏 O(n)。
  • ArrayList get: O(1). Insert in the middle: O(n).ArrayList 按下标读：O(1)；中间插入：O(n)。
  • A double loop over the same list: O(n²) — too slow for big data.对同一个列表写两层循环：O(n²)，数据一大就慢。

In an interview, say the number and why: “O(1), because it computes the bucket from the hash.”面试时说数字，并且说原因：“O(1)，因为它是用 hash 直接算出桶的位置。”

  2. Why is reading an array O(1)?为什么读数组是 O(1)？
  3. A bucket with 8 items: how many steps at most?桶里有 8 个元素：最多几步？

Answer out loud first. Only then open the answers below.先自己出声答，再看下面的答案。

Answers参考答案
01Steps grow in a straight line with n: double the data, double the steps.步数和 n 成正比：数据翻倍，步数也翻倍。
02One multiplication and one addition give the address. No loop, no search.一次乘法加一次加法就算出地址，没有循环、没有查找。
03If the bucket has treeified: about 3 comparisons (log₂8). If it is still a list: at most 8.已经树化：约 3 次比较（log₂8）；还是链表：最多 8 次。
