HashMap methods, and how they look in real codeHashMap 的常用方法，以及它们在真实代码里长什么样

Six methods cover almost everything: put, get, getOrDefault, computeIfAbsent, merge, remove.六个方法能盖住几乎所有场景：put、get、getOrDefault、computeIfAbsent、merge、remove。

Short answer先给答案Six methods cover almost everything: put (add or replace), get (read), getOrDefault (read with a default), computeIfAbsent (compute and store only if missing), merge (combine old and new), remove (delete).六个方法基本够用：put 存或覆盖；get 读；getOrDefault 读不到给默认值；computeIfAbsent 没有才算并存入；merge 合并新旧值；remove 删除。

02Real code: a cache真实代码：缓存

// 没有就查数据库，再放进缓存（最常见的写法）
User user = cache.computeIfAbsent(userId, id -> userMapper.selectById(id));

One line: read the cache, miss → query the database → write back. No null check, no two lookups.一行：读缓存，没命中——查库——写回。不用判空，也不用查两次。

In a real service add an expiry (Caffeine or Redis). computeIfAbsent keeps the map small, but it never forgets.真实服务里还要加过期（Caffeine 或 Redis）。computeIfAbsent 只是让它懒加载，但不会自己忘。

03Real code: counting真实代码：计数

// 统计每个状态有多少单
Map count = new HashMap<>();
for (Order o : orders) {
    count.merge(o.getStatus(), 1, Integer::sum);
}

merge is the cleanest counter: old value + 1, or 1 if it is the first time.merge 是最干净的计数写法：老值 +1，第一次出现就给 1。

04Real code: grouping真实代码：分组

// 按用户分组：Map>
Map> byUser = new HashMap<>();
for (Order o : orders) {
    byUser.computeIfAbsent(o.getUserId(), k -> new ArrayList<>()).add(o);
}

Or with the stream API: orders.stream().collect(Collectors.groupingBy(Order::getUserId)) — it does the same thing internally.也可以用 stream：orders.stream().collect(Collectors.groupingBy(Order::getUserId))，内部做的就是同一件事。

05Four things that bite四个坑

  • get returns null — use getOrDefault when the value may be missing.get 返回 null——可能没有的时候用 getOrDefault。
  • Mutable keys — if you change a field used in hashCode() after put, the key is lost.可变的 key——put 之后改了参与 hashCode() 的字段，这个 key 就找不回来了。
  • No order — HashMap does not keep order. Use LinkedHashMap or TreeMap.无序——HashMap 不保证顺序，要顺序用 LinkedHashMap 或 TreeMap。
  • Not thread-safe — lesson 7.线程不安全——第 7 课讲。
