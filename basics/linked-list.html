What is a linked list?

Notes with arrows. You cannot jump; you follow the next pointer.

Basicsdata structure

01The idea

Think of it like thisA treasure hunt. Each note says one thing: the next place. You cannot jump to the end. You follow the arrows, one note at a time.

A linked list is made of small boxes called nodes. Each node has two parts:

  • a value (the thing you want to keep),
  • a pointer to the next node.

The first node is called the head. The last node points to null — nothing. That means “this is the end”.

02Difference from an array

ArrayLinked list
Where it livesboxes next to each otherboxes anywhere in memory
Read item 500jump straight there — O(1)walk 500 steps — O(n)
Insert in the middlemove everything after — O(n)change two arrows — O(1)
Extra costnoneeach node stores one extra pointer

03In Java

LinkedList<String> list = new LinkedList<>();
list.add("Ann");
list.add("Bob");
list.get(1);        // "Bob" — but it walks from the head

You will meet this shape again in HashMap: when two keys land in the same bucket, they form a linked list — each Node has a next pointer. That is exactly the treasure hunt.
