What is an array?

A row of boxes with numbers. If you know the number, you jump straight to the box.

Basicsdata structure

01The idea

Think of it like thisTen lockers in a row. They touch each other. Each locker has a number: 0, 1, 2 … 9. If you know the number, you walk straight to that locker. You do not open the other nine first.

An array is that row of boxes. It has two facts:

  • The boxes are next to each other in memory.
  • Each box has a number, called an index. The first index is 0, not 1.

02Why reading is fast

Because the boxes touch each other, the computer can compute the address:

address = start + index × size_of_one_box

So reading box 500 costs the same as reading box 0. One step. In Big O words, this is O(1) — constant time.

03Why inserting is slow

The boxes are full and touching. If you insert an item in the middle, every item after it must move one step to the right. With one thousand items, that is one thousand moves. This is O(n) — linear time.

RememberAn array is like a bookshelf where every book must stand next to the next one. Adding a book in the middle means pushing all the books after it.

04In Java

int[] scores = new int[10];   // 10 boxes, all 0
scores[0] = 90;               // put 90 in box 0
int first = scores[0];        // read box 0

String[] names = {"Ann", "Bob", "Cid"};   // 3 boxes, already filled

You already met arrays today, even if you did not know it: ArrayList uses an array inside, and HashMap uses an array of buckets. The array is the most common box in Java.
