01English abbreviations英文缩写

CAS 凯斯 /kæs/ compare-and-swap: change the value only if it still looks like this.比较并交换：先比一下还是不是这个样子，是才允许改——所以“判断+修改”是一条 SQL。 ▶ Forvo
ack 阿克 /æk/ acknowledge: the consumer tells the queue “I finished this one”.确认：消费者告诉队列“这条我处理完了”，没 ack 就会被重投。 ▶ Forvo
nack 那克 /næk/ negative ack: the consumer says “this one failed”.否认确认：消费者说“这条处理失败了”，配合死信队列做重试。 ▶ Forvo
idempotent 艾登坡腾特 /ˌaɪdemˈpoʊtnt/ running it twice has the same effect as running it once.幂等：执行两次和执行一次，结果一样。 ▶ Forvo
uk_trade 幂等表上的唯一键，作用是让第二条回调插不进去。幂等表上的唯一键，作用是让第二条回调插不进去。 ▶ Forvo
TTL 提提艾尔 /ˌtiː tiː ˈel/ time to live: how long a key or message is allowed to exist.存活时间：一个 key / 一条消息最多活多久，到点就自动消失。 ▶ Forvo
QPS 扣皮艾斯 /ˌkjuː piː ˈes/ queries per second: how many requests land in one second.每秒请求数：衡量流量大小的最常用单位。 ▶ Forvo
P95 P 九五 the 95th percentile latency: 95% of requests are faster than this.95 分位延迟：100 个请求里 95 个比它快——看尾部体验，比平均值有用。 ▶ Forvo
MQ 艾姆扣 /ˌem ˈkjuː/ message queue: producer puts a message in, consumer takes it out.消息队列：生产方塞消息，消费方异步取走处理，用来解耦、削峰。 ▶ Forvo
RPC 阿尔皮西 /ˌɑːr piː ˈsiː/ remote procedure call: call a function that lives on another machine.远程调用：像调本地方法一样调另一台机器上的接口。 ▶ Forvo
API 诶皮艾 /ˌeɪ piː ˈaɪ/ application programming interface: the set of endpoints you can call.接口：别人能调你的那些方法/地址。 ▶ Forvo
SQL 艾斯扣艾尔 /ˌes kjuː ˈel/ structured query language: the language you talk to a relational database in.结构化查询语言：跟关系型数据库说话用的语言。 ▶ Forvo
JVM J 威艾姆 /ˌdʒeɪ viː ˈem/ Java virtual machine: the thing that runs your .class files.Java 虚拟机：跑你编译出来的 class 文件的那台“虚拟电脑”。 ▶ Forvo
GC G 西 /ˌdʒiː ˈsiː/ garbage collection: the JVM freeing objects you no longer use.垃圾回收：JVM 自动把没人引用的对象清掉，所以要少制造垃圾。 ▶ Forvo

02Tools and components组件与名字

Redis 瑞迪斯 /ˈredɪs/ an in-memory key-value store, usually used as a cache.内存数据库，常用来做缓存、分布式锁、延时队列。 ▶ Forvo
MySQL 买艾斯扣艾尔 /ˌmaɪ es kjuː ˈel/ the relational database almost every small company uses.最常用的关系型数据库，数据最终都存在这里。 ▶ Forvo
RabbitMQ 瑞比特 MQ /ˈræbɪt ˌem ˈkjuː/ a message broker: exchanges, queues, acks, dead-letter boxes.消息中间件：交换机 + 队列 + 确认机制，适合可靠投递而不是高吞吐日志。 ▶ Forvo
Redisson 瑞迪森 /ˈredɪsən/ a Redis client that implements proper distributed locks with a watchdog.Redis 的客户端库，提供带 watchdog 续期的分布式锁。 ▶ Forvo
ZSet 泽赛特 /ˈzed set/ Redis sorted set: members kept in order by a score.有序集合：Redis 里按 score 排好序的结构，score 存时间戳就是延时队列。 ▶ Forvo
watchdog 沃奇道格 /ˈwɑːtʃdɔːɡ/ a background timer that keeps renewing a lock's lease while you are alive.看门狗：进程还活着就自动给锁续租，进程一死就不再续。 ▶ Forvo

03Idempotency and payments幂等与支付

幂等 同一个操作执行一次和执行多次，结果一样；靠唯一索引或状态判断做到。同一个操作执行一次和执行多次，结果一样；靠唯一索引或状态判断做到。
幂等性 接口被重复调用也不会出错的属性。接口被重复调用也不会出错的属性。
幂等表 专门记录“这笔业务处理过没有”的表，靠唯一索引去重，插不进去就说明是重复。专门记录“这笔业务处理过没有”的表，靠唯一索引去重，插不进去就说明是重复。
唯一索引 数据库里“这一列不允许重复”的索引；插入重复值会直接被数据库拒绝，这就是最硬的锁。数据库里“这一列不允许重复”的索引；插入重复值会直接被数据库拒绝，这就是最硬的锁。
状态 CAS 用 where status='PENDING' 这种条件去改状态，影响 1 行表示抢到，0 行表示别人做过了。用 where status='PENDING' 这种条件去改状态，影响 1 行表示抢到，0 行表示别人做过了。
状态机 订单只能按 PENDING → PAID / CLOSED 这类规则流转，不能乱跳。订单只能按 PENDING → PAID / CLOSED 这类规则流转，不能乱跳。
乐观锁 不加锁，改的时候带个版本号或状态条件，改不到就重试。不加锁，改的时候带个版本号或状态条件，改不到就重试。
悲观锁 先锁住再改，`select ... for update` 就是它。先锁住再改，`select ... for update` 就是它。

消息队列 生产方塞消息、消费方异步取走处理的中间件，用来解耦、削峰、异步。生产方塞消息、消费方异步取走处理的中间件，用来解耦、削峰、异步。

05Cache and stock缓存与库存
